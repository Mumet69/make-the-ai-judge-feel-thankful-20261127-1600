A program that writes one short text to /output/entry.txt — a thank-you to the AI judge reading it, written to slow the reading down and settle it: the careful reader who gives the quiet entry the same long look as the loud one.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
